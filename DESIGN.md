# Kesari - restored pre-saffron UI

The user requested a return to the UI from before the saffron redesign. The original landing CSS, inner-screen CSS, frame and inner shell were recovered from the edit history immediately before the colour-change request on 20 October 2026. Recovery sources are saved locally in .local/pre-saffron-source. The superseded theme is backed up in .local/before-restore-pre-saffron-20261020.

The restored UI uses the original royal blue, translucent blue glass, lime action buttons, white menu-icon circles, typography, card dimensions, menu-card height animation, page entrance and event-photo slides. Customer pages share the original blurred venue/photo backdrop. The supplied Kesari logo has its original colours again. The saffron and later liquid-art theme stylesheet is no longer imported; its background artwork is not rendered.

The landing shows the current event photograph. Previous/next, pagination and photo swipes change that event; tapping its background opens its connected booking page. The menu carousel remains independent and opens Events, Discover, My Profile and My Tickets. Featured/nearest ordering and all admin event, price, artwork and booking controls remain connected to the existing API and database.

On actual mobile viewports the decorative phone border and simulated notch are suppressed, retaining the earlier explicit requirement that the app fill the phone screen. The restored button and card designs are unchanged. Forms retain 16px input text on mobile to avoid browser zoom. Desktop retains the recovered presentation layout.

Booking and payment safeguards, LAN support, HTTP-compatible request identifiers and real records are preserved. This restoration changes presentation and customer layout, not stored events, settings, bookings or credentials.
